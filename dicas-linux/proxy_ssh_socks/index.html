Proxy SSH SOCKS

Wed, 28 Oct 2020

Exemplo de subida de proxy (SOCKS) localmente:

ssh -D 8080 -C -N usuario@servidor -p porta

Sendo:

  • 8080: É a porta que ficará em listen para o seu proxy. É a porta que você irá configurar no seu navegador.
  • usuario: É o usuário para a conexão ssh
  • servidor: É o servidor ssh
  • porta: É a porta do servidor ssh

Exemplo com CRIPTOGRAFIA e LIBERANDO NA REDE LOCAL

ssh -N -p 443 -g -C -c blowfish-cbc -D 8080 usuairo@servidor -p porta
