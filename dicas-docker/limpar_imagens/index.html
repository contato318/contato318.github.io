Limpar dangling images

Thu, 29 Oct 2020

Por vezes, geramos “dangling images” quando usamos docker.

“Dangling images” são imagens que não possuem uma tag.

Se você alguma(s) vez(es) rodou um Dockerfile que falhou, provavelmente você deve ter uma ou mais imagens sem tags.

Para removê-las, basta executar:

docker rmi $(docker images -q -f dangling=true)
